# Operator trial

The trial appears only when the Work Surface is powered and the traveler has the five-discipline derived Workshop capability: inference, temporal reasoning, construction, hidden perception, and self-surpass.

There is no predetermined password. The traveler constructs a 5×5 glyph. A valid glyph must contain 7–11 connected orthogonal cells, cross the center, touch both top and bottom edges, and contain at least one branch point. Many constructions can satisfy the rules.

Success grants `operator`. This authorizes the Work Surface interface but this module does not itself create or expose the Workshop route.
