# Reality Foundry — sprint handoff / revenue pause

Status: Mobile-accessible conceptual G36 viewer deployed at https://godsun108.github.io/The-portal/reality-foundry/ . User confirmed it renders and responds on iPhone. Subsequent mobile usability changes are committed but not independently device-certified.

## What is implemented
- Standalone HTTPS browser-native Canvas wireframe, nine illustrative components.
- Rotation, pinch/scroll zoom, animation timeline, explode and component visibility.
- Evidence-labeled conceptual assembly relationship inspector.
- Responsive compact mobile layout.
- No third-party runtime dependencies for this page.

## What is NOT implemented
- No photogrammetry, live camera scanner, 3D reconstruction, real CAD import in this public page.
- No physical constraint solver, collision detection, validated dynamics, or engineering certification.
- No independently verified device tests for the latest edits.
- Private virtual-human-engine development code/assets are not exposed here.
