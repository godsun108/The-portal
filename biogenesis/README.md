# BioGenesis Molecular Observatory — research preview v0.1

## Scope
This is an offline-capable, static scientific-literature exploration interface in `biogenesis/index.html`, intended for iPhone and desktop. It is an evidence-first foundation, **not** a drug-discovery engine, quantum simulator, molecular docking engine, or treatment recommendation system.

## What works in source
- Select a melittin or venom phospholipase A₂ literature topic.
- View a clearly labeled conceptual membrane cross-section and move a generic illustrative molecule.
- Inspect evidence categories and explicit limits on clinical claims.
- Open a relevant PubMed search in a separate tab.
- See the current status of unperformed calculations and experiments.

## What is not yet verified
- Browser rendering on iPhone or desktop.
- Actual molecular structures, binding predictions, or dynamic simulations.
- Any antiviral efficacy, selectivity, safety, or medical utility.
- Live Genesis integration, automatic literature ingestion, or research journal persistence.

## Scientific provenance and future gates
1. Retrieve literature metadata and verify primary sources and molecular structure provenance.
2. Integrate a vetted, read-only molecular structure viewer with explicitly identified structure identifiers.
3. Benchmark scientific calculations against known reference data and report uncertainty.
4. Store immutable evaluation artifacts and connect them to the Genesis progress contract.
5. Require human review for claims of efficacy or improvement; do not autonomously synthesize compounds, optimize toxic agents, or recommend clinical use.

No private Victory/VictoryChain code or data is used. No paid services, new dependencies, deployment, or model training are required for this preview.
