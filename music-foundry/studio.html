PROJECT NOTES

NO UPLOADS

This first studio foundation supports imported audio tracks, clip start offsets, per-track gain and pan, mute/solo, synchronized playback, and offline stereo WAV rendering. It does not yet provide MIDI instruments, time-stretching, plugin hosting, persistent project files, or Genesis-controlled editing. Use the existing Recording Booth for microphone capture and Vocal Timeline for the established spoken-take workflow.

Audio files remain in memory for this browser session. Export your mix before refreshing or closing the page. iPhone/Safari performance and file-export behavior still need real-device testing.
