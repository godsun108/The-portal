# Bounded Game Master

Portal Intelligence may propose, but not directly perform, world actions.

Allowed proposal classes:
- route to an allowlisted internal destination
- challenge at an allowlisted game/room
- begin an allowlisted local fictional World Event

Every proposal is validated by deterministic browser code and requires explicit traveler acceptance. Model output cannot invent destinations, grant artifacts, create scars, unlock secrets, alter physics, execute code, spend money, trade, or bypass progression.
