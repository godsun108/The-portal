# Portal cohesion layer

The Portal should feel like one universe rather than a collection of pages. Shared atmosphere is intentionally subtle: rooms retain their identities while traveler state has a consistent visual vocabulary.

- bottom-right traveler glyph: portable state awareness
- violet ambient field: ordinary Portal depth
- red ambient field: REDSHIFT
- reduced-motion preference is respected
- no effect may obscure factual content or become evidence for external events
