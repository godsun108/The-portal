# Intelligence world context

Portal Intelligence may receive a read-only `portal.world-context.v1` envelope built from actual browser-local Portal state. It can interpret the traveler's artifacts, scars, discoveries, physics, active local world events, signal progress and recent game outcomes.

Model text is not authority. A mind cannot grant artifacts, create scars, complete games, begin events, unlock secrets, change physics or mutate canonical world state merely by returning prose. Those mutations remain owned by deterministic Portal mechanics and separately authorized tools.

The model must distinguish fictional Portal world state from external real-world facts.
