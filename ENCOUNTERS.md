# Rare encounters

Rare encounters create wonder from canonical Portal state. They are deterministic within 30-minute local buckets: the same room, traveler state and event state produce the same roll. This makes rarity reproducible and testable rather than opaque randomness.

Encounters never claim a real person visited, a remote event occurred, or an AI sent a message unless a verified source establishes that separately. Current encounters are atmospheric interpretations of local state.
