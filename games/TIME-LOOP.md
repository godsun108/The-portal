# TIME//LOOP

A temporal coordination cabinet. Each six-second loop records the traveler's position frame by frame. On reset, that recording returns as a ghost and repeats exactly while the current traveler makes a new attempt. The puzzle is solved when two separated anchors are occupied simultaneously by any combination of current traveler and past ghosts.

Clear within two loops for mastery artifact `chronokey`; a later clear grants `loop-thread`. Failing to solve within five loops records `time-fray`.
