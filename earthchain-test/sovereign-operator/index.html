Security notes

Peer fingerprint approval is manual and applies only to this connection. Host identity and replay storage are currently experimental and not yet durable across restarts. The desktop must remain running. If a request times out or disconnects, check the desktop's local audit log before retrying; the operation may have completed even if the phone did not receive its receipt.

This controller is experimental. Do not use it for financial actions, secrets, or destructive commands.
