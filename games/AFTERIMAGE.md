# AFTERIMAGE

A seven-round visual memory cabinet. A 5x5 field briefly displays an increasingly large signal pattern, then clears. The traveler reconstructs the pattern from memory and locks the answer.

Scoring penalizes both missed signals and false selections. At least 82% total recall grants `afterimage`; at least 95% grants mastery artifact `perfect-memory`. Lower accuracy records `memory-static`. Converged physics shortens observation time slightly rather than changing the answer.
