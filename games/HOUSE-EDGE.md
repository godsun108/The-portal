# HOUSE//EDGE

A compact five-room roguelike deck-builder. Each run starts with the same small deck, then the traveler drafts one of three stronger cards after each cleared room. Cards trade damage, shield, and integrity; enemies become stronger through the table.

A clear grants `house-mark`. A failed run records the `house-took-its-cut` scar. The run deck is ephemeral; canonical outcomes use the shared Portal Games protocol.
