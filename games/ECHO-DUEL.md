# ECHO//DUEL

A local asynchronous self-duel. The cabinet records the traveler's normalized movement path and replays the saved best path on the next run as a visible echo. Both current traveler and echo traverse the same newly generated signal field, so the rival is genuine recorded input rather than a fabricated human opponent.

Winning stores the new run when it improves the saved completion time and grants `self-rival`. Collecting all twelve signals while defeating an existing echo grants mastery artifact `echo-breaker`. Losing records `outpaced-by-self`.
