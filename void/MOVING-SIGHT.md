# MOVING SIGHT

Derived from `zero-crown` + `peripheral-eye`. In the Void, an impossible stair gradually manifests only when keyboard movement is directed away from the current pointer/look vector. Direct movement toward attention drains the manifestation. Once sufficiently visible, interacting records `backstep` locally.

This is an in-world capability consequence, not a menu unlock. It does not reveal WORKSHOP or consume either mastery artifact.
