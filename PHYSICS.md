# Portal Physics

Portal Physics is a bounded client-side world-state layer. Surface visitors keep ordinary behavior. A traveler carrying the `convergence` artifact enters `converged` physics.

Current laws:
- **depth** — opted-in elements respond subtly to pointer position.
- **phase** — opted-in elements acquire a slow visual phase oscillation.
- **gravity drift** — shared CSS variables expose bounded directional drift for rooms/games to interpret.

Physics must remain accessible, non-destructive and local. It does not imply external events or alter factual data. Rooms opt into effects through data attributes or exported helpers.
