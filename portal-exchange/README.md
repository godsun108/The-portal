# Portal Exchange — research-only prototype
This static, iPhone-friendly design preview demonstrates three proposed paths: card, bank, and XRP. No payments, swaps, wallet signing, private-key collection, real quotes, balances, token issuance, or provider integration occur. Never ask users to paste credentials or seed phrases.

## Production gates
1. Define EARTH token issuance, supported chain, supply, utility and governance; independently assess token regulatory classification.
2. Determine legal operating model and partner responsibilities for US federal and Florida money-transmission rules, KYC/AML/sanctions, card/bank compliance, taxes and consumer protection. Seek qualified legal review.
3. Choose vetted regulated payment/onramp partners; verify their actual EARTH support before advertising availability.
4. For XRP-to-EARTH, verify a real token, actual supported trading pair or routing, executable liquidity, fees, slippage, network settlement, refunds and failure handling. Do not invent a price.
5. Implement audited wallet connection and transaction signing with no server-side secret collection.
6. Use noncustodial/provider-managed flows where viable; do not create a homemade exchange or custody operation without the necessary approvals.
7. Add reconciliation, receipts, risk limits, disputes, monitoring and security tests before any live financial transactions.

## Current status
The page is intentionally disconnected from the existing ECTEST marketplace and cannot credit real EARTH or spend it. Nothing deployed.
