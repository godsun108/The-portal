# WORLD CLOCK

WORLD CLOCK is an existing local Portal station backed by `events.js`. REDSHIFT and STILLNESS are explicitly fictional, browser-local world events.

## ECHO TIME

Travelers with the derived `echoTime` capability (`chronokey` + `echo-breaker`) see an additional chamber. RECALL A MOMENT selects only from genuine `portal-game-history` records in the current browser and renders the recorded game, timestamp, and outcome. If no history exists, it says so rather than fabricating a memory. A successful recall grants `remembered-moment`.
