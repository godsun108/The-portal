# THE PORTAL

> Welcome to the other internet. Pick a door.

A mobile-first anti-Linktree: one entrance to small, strange, interactive corners of the web.

## v0.1

- Portal landing page
- Earth Now, Window and Oracle doors
- Built-in **CHAOS** engine with persistent press count and rare events
- A curiosity-driven ??? interaction
- Zero framework/runtime dependencies
- GitHub Pages friendly

## Rule

**No boring pages. Every link earns the click.**

The Portal is intentionally separate from Victory and contains no credentials, private APIs, wallets, or privileged integrations.
