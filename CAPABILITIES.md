# Portal capability combinations

Schema: `portal.capabilities.v1`.

Mastery artifacts are interpreted as demonstrated capabilities rather than XP. Combination predicates are derived from artifact state and are not separately granted achievements.

Current predicates include sideways reading (perception + inference), repair (building + execution), echo-time (temporal planning + self-surpassing), orbital tactics (strategy + prediction), moving sight (movement + perception), and a five-discipline workshop predicate.

The combination table is infrastructure, not a player-facing recipe book. Consequences should appear in-world. The first consequence is an unmarked broken Arcade cabinet that manifests only for travelers who have both `maker-sigil` and `vector-core`. Interacting with it grants `repair-mark` and persists the local repair. No Workshop route is exposed by this file.
